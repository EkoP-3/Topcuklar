# Silah görselleri

Buraya `<silah-id>.png` (veya `.webp`) koyarsanız oyun o silahı çizim yerine bu görselle gösterir.
Dosya adı karakterin kimliğiyle aynı olmalı: `drill`, `chime`, `pylon`, `grapple`, `lance`, `maul`
(yeni karakter eklenince onun `id`'si).

Görsel kuralları:

- Şeffaf arka plan.
- Silah **sağa** bakmalı: sap solda, uç sağda (yatay, düz).
- Silaha sıkı kırpılmış olsun (kenarlarda boşluk kalmasın).
- Önerilen boyut: uzun kenarı 512–1024 px.
- Görselin en/boy oranı korunur; uzunluk silahın menziline göre ölçeklenir.
